# COMPUTER – AI Agent & Personal Assistant

Ein autonomer KI-Assistent mit Sprachsteuerung, Smart Home Integration, Browser-Automatisierung und Web-Dashboard.

## Features

**Sprachsteuerung**
- Sprich einfach – kein Wake-Word nötig
- Edge-TTS mit wählbaren Stimmen
- Interrupt-System: Rede rein, er stoppt

**AI Agent**
- Multi-Step Task Planning
- Autonome Aufgabenausführung
- Retry-System bei Fehlern
- Tool-basierte Architektur

**Smart Home (Govee)**
- Licht an/aus, Farben, Helligkeit
- Stimmungsmodi (Gaming, Chill, Film)
- Licht-Timer und Licht-Wecker

**Browser-Automatisierung**
- Webseiten steuern per Sprache
- Klicken, Tippen, Scrollen
- Seiten vorlesen lassen

**Integrations**
- WhatsApp (über WhatsApp Web)
- Email (Gmail, Outlook, GMX)
- Discord Bot
- Webhook-System

**Produktivität**
- Notizen & To-Do Listen
- Timer & Erinnerungen
- Habit-Tracker mit Streaks
- Tagebuch per Sprache
- Geburtstags-Erinnerungen

**System-Steuerung**
- Apps öffnen/schließen per Sprache
- Musik steuern (Play, Pause, Skip)
- Lautstärke per Sprache
- PC herunterfahren/neustarten/sperren
- Bildschirmaufnahme
- Multi-Monitor Fenster verschieben

**Tools**
- Wetter (Open-Meteo, kostenlos)
- Nachrichten vorlesen (RSS)
- Wikipedia-Suche
- Übersetzen (16+ Sprachen)
- Währung & Einheiten umrechnen
- Krypto-Watchlist
- Passwort-Generator
- QR-Code erstellen
- Spotify Song-Erkennung
- Datei-Suche

**Web-Dashboard**
- Sci-Fi Control Center UI
- Funktioniert auf PC und Handy
- System-Monitor (CPU, RAM, Disk, Akku)
- Live Action-Logs
- Tool-Manager
- Agent Task-Übersicht
- Einstellungen (Stimme, Speed, AI-Provider)

**Custom Commands**
- Eigene Befehle per Sprache erstellen
- Streaming-Profile (OBS + Chatterino + Game)
- Gaming/Chill/Arbeitsmodus
